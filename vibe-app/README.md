# English Vibe App

シンプルで使いやすい、英単語学習用のミニWebアプリです。  
ビルドツール不要で、`index.html` を開くだけで動きます。

## 機能

- 日本語UI
- 英単語30語（日本語の意味 + 簡単な例文）
- フラッシュカードモード
- 4択クイズモード
- 学習進捗の保存（`localStorage`）
  - 正解数
  - 回答数
  - 正答率
- 日次連続学習ストリーク（ローカル日付ベース）
- ダークモード切り替え
- モバイルファーストのレスポンシブデザイン

## 使い方

1. このフォルダを開く
2. `index.html` をブラウザで開く
3. 上部タブでモードを切り替える
   - **フラッシュカード**: 単語を見て意味を確認
   - **4択クイズ**: 意味を4択から選ぶ

## 進捗データについて

進捗はブラウザの `localStorage` に保存されます。  
同じブラウザ・同じ端末なら、次回起動時にも引き継がれます。

## ファイル構成

- `index.html` - 画面構成
- `styles.css` - スタイル（ライト/ダークモード、レスポンシブ）
- `app.js` - 単語データ、学習ロジック、保存処理
