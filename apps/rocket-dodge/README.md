# ロケット・ドッジ 🚀

ブラウザで遊べるシンプルな回避アクションゲームです。

- 隕石を避ける
- 星を集めてスコア獲得（+10）
- 時間経過で難易度アップ
- ハイスコアは `localStorage` に保存
- キーボード操作 + モバイル向け画面操作
- サウンド ON/OFF、一時停止、リスタート対応

## 遊び方

### そのまま開く
1. `index.html` をブラウザで開く

### ローカルサーバーで開く（推奨）
Python がある場合:

```bash
cd /home/rui/.openclaw/workspace/apps/rocket-dodge
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000` を開く。

## 操作

- キーボード: 矢印キー / WASD
- ポーズ: ボタン or `P`
- モバイル: 画面下の方向ボタン、またはキャンバス上ドラッグ

## ファイル構成

- `index.html` … UI とキャンバス
- `style.css` … レイアウト/レスポンシブスタイル
- `script.js` … ゲームロジック（描画、当たり判定、難易度、音、保存）
