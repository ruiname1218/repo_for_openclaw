# 電卓アプリ

シンプルな HTML/CSS/JavaScript 製の電卓アプリです（ビルドツール不要）。

## 機能

- 四則演算（+ / - / × / ÷）
- 小数点入力
- パーセント（%）
- 符号切替（+/-）
- C（現在入力クリア）、AC（全クリア）、⌫（1文字削除）
- キーボード入力対応
- 計算履歴パネル（`localStorage` 永続化）
- ダークモード切替（設定は `localStorage` 保存）
- モバイルファーストのレスポンシブレイアウト
- エラーハンドリング（0除算・不正な式など）

## 使い方

### 1) ファイルを開く

`calculator-app/index.html` をブラウザで直接開くだけで利用できます。

### 2) ローカルサーバーで実行（任意）

```bash
cd calculator-app
python3 -m http.server 8000
```

ブラウザで以下を開きます：

- http://localhost:8000

## キーボード操作

- `0-9`: 数字入力
- `+ - * /`: 演算子
- `.` または `,`: 小数点
- `Enter` / `=`: 計算実行
- `Backspace`: 1文字削除
- `Esc`: AC（全クリア）
- `%`: パーセント
